# 💻 Laptop-Finder (TechFinder Pro)

TechFinder Pro is an interactive, intelligent laptop recommendation, configuration, and invoice generation platform.

🔗 **Live Website**: [https://bhootibaba25-bit.github.io/Laptop-Finder/](https://bhootibaba25-bit.github.io/Laptop-Finder/)

---

## ⚡ Dual Recommendation Engines

1. **📦 Curated Catalog (Instant)**
   - Curated in-memory database of 100+ verified retail laptops across Student, Business, Gaming, and Creator categories.
   - Works immediately for all visitors with zero setup.

2. **✨ AI Live Market (Real-Time)**
   - Powered by Google Gemini 1.5 Flash.
   - Dynamically searches real-world laptop hardware matching your exact budget and custom prompt requirements (*e.g., "16GB RAM for Machine Learning and Docker under 85,000"*).
   - Generates realistic retail market models, specs, and price brackets with an intelligent `👑 Best Value` calculation.
   - API keys are securely saved in the user's browser `localStorage` and never shared or exposed publicly.

---

## ✨ Features

- **Smart Multi-Parametric Search**: Filter by budget (in INR Rs.), usage category, sort order, and brand.
- **Custom Hardware Configurator**: Customize memory (RAM) and SSD storage with instant real-time price updates.
- **Official Tax Invoice Generator**: Generates formatted, itemized tax invoices with automated order IDs, dates, and 18% GST calculation.
- **Print & PDF Export**: Clean `@media print` styling ready for 1-click official invoice downloads.
- **Skeleton Shimmer Loading**: Smooth UI animations during AI generation.
