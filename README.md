# 💻 Laptop-Finder (TechFinder Pro)

TechFinder Pro is an interactive laptop recommendation, configuration, and invoice generation platform.

🔗 **Live Website**: [https://bhootibaba25-bit.github.io/Laptop-Finder/](https://bhootibaba25-bit.github.io/Laptop-Finder/)

---

## ✨ Features
- **Smart Filtering**: Filter over 100 laptops by budget, usage category (Student, Business, Gaming, Creator), and brand.
- **Value Scoring**: Highlights the `👑 Best Value` option based on RAM-to-price ratio.
- **Custom Hardware Configurator**: Customize memory (RAM) and solid-state storage (SSD) with real-time price recalculation.
- **Official Tax Invoice Generator**: Generates formatted, itemized tax invoices with automated order IDs, dates, and 18% GST calculation.
- **Print & PDF Export**: Instant 1-click print-ready styling formatted cleanly for PDF downloads.
